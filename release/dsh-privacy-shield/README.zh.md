# dsh-privacy-shield 隐私护盾

**一句话**：在 DeepSeek Harness（DSH）里和 AI 聊天时，把消息里的隐私内容（手机号、身份证号、公司名、地址……）在**本机**换成看不出原值的代号再发给云端模型，模型回答后又在界面上换回真值给你看。

**版本 1.1.0** · MIT 开源 · 装完即用 · 无任何第三方依赖

---

## 它是怎么工作的

```
你输入的：      请联系张三 13800138000，车牌京A12345。
发给模型的：    请联系 <PERSON_1a2b3c4d> <PHONE_9f8e7d6c>，车牌 <PLATE_0a1b2c3d>。
你在界面看到的：请联系张三 13800138000，车牌京A12345。
```

代号 = 类别标签 + 随机编号，由本机密钥生成，拿到代号的人猜不出、也推不出原值。

你的本地聊天记录、界面显示、文件导出**始终保持原样**——换代号只发生在"发出去的那一份"上。

## 它能帮你做什么

- **自动识别敏感信息**：手机号、身份证、银行卡、邮箱、车牌、护照，以及中文场景常用的公司/机构名、项目名、系统名、各类编号、地址、人名，共 28 类。发出去之前自动换成代号，不用你做任何事。
- **表格也认得**：粘贴表格内容时按列标题判断哪列是人名、哪列是单位，整列自动脱敏；金额列默认不动，不妨碍让 AI 帮你算账统计。
- **JSON 工具结果也认得**：AI 读完表格打印出来的 JSON——哪怕是被截断、带行号的 pretty-print（已经不合 JSON 语法）——照样按表头逐列遮；键值对（`"销售": "…"`）、聚合名单（`{"paid_by_sales": {"…": 6}}`）和工作表名一起遮。
- **裸编号也抓得到**：`cstb-pmc-2020245`、`京分-CSTM-PME(PMC)-2020230` 这类合同号/项目号按结构识别，不需要前缀或引导词；纯日期不动。
- **见过就记住**：从表格单元格或键值对学到的真值，之后出现在散文里（哪怕是中文紧贴写法）也会被遮，带边界校验避免误伤普通词。
- **可以教它认你的专有名词**：扫描本地文档（`/shield scan-doc`）或从聊天历史学习（`/shield learn`），把你单位的人名、项目名加进词表——候选必须经你确认才生效。候选由多路召回（表头列语义、同句上下文、名称后缀、引号内标题、重复出现），每条都带"凭什么推荐它"的证据；前面没有"项目/客户"这类引导词的名字，照样会被提出来。
- **规则可以搬家**：词表和开关可打包导出/导入（支持口令加密），换电脑、发同事都方便；规则包绝不包含原文对照表。
- **每次都自动复查**：每发一条消息，插件都会再检查一遍"有没有漏网的明文"，记录里只有数量和类型统计，不含内容本身。
- **有图形界面**：输入框旁有状态条，点开面板就能调设置、管词表、做脱敏测试、看检查记录。

> **两条边界**：① 图片内容不处理（不做图片识别），含敏感信息的图片请不要发送；② 本地日志保留原文是刻意设计——这是界面上能还原真值的前提。请做好本机的磁盘加密与权限管理。

## 怎么安装

**方式一：Git 仓库安装**（推荐，能自动更新）

在 DSH 里对助手说：

```
plugin_manager action=install_bundle target=https://github.com/hhl123hhl/dsh-privacy-shield.git
```

**方式二：离线包安装**

把 Releases 里的 `.zip` 解压，然后：

```
plugin_manager action=install_bundle target=<解压目录的绝对路径>
```

两种方式装完都要**重启 DSH**。默认配置装好即用；进阶配置见 [docs/CONFIG.md](docs/CONFIG.md)。

验证安装：

- `/shield status` —— 看模式、识别类别、拦截次数
- `/shield verify 张三的手机号是13800138000` —— 试跑一次脱敏（只显示结果，不影响聊天）

## 常用命令

| 命令 | 作用 |
|---|---|
| `/shield status` | 看状态：模式、类别、统计 |
| `/shield verify 文字` | 试脱敏，只看结果 |
| `/shield scan-doc 路径` | 扫描文档，提取专有名词候选 |
| `/shield learn` | 从聊天历史学习高频词候选 |
| `/shield export / import` | 导出 / 导入规则包（可加口令加密） |
| `/shield audit` | 看出境复查记录（只有统计） |
| `/shield doctor` | 自检 |
| `/shield off / on` | 临时关闭 / 恢复（重启后按配置） |

## 和别的脱敏插件有什么不同

1. **只动"发出去的那一份"**：本地记录永远原样，你随时能核对它遮了什么。
2. **代号由本机密钥生成**：外人拿到代号也无法枚举或反推你的信息。
3. **规则包绝不含原文对照表**：配置文件即使丢失，也不会泄露原文。
