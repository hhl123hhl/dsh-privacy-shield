# dsh-privacy-shield v1.1.0 发布说明

日期：2026-10-29　｜　上一版：v1.0.1

## 新功能

### 1. 表格列语义脱敏

粘贴表格（Excel 复制出来的 TSV、CSV、Markdown 表格）时，插件按**列标题**判断这一列是什么：联系人列、单位列、合同编号列……整列自动脱敏，单元格里的裸人名、裸机构名不再需要"姓名："这类前缀也能遮住。类型、是否、计数这类枚举列一律不动。

### 2. 机构名补漏

机构名识别增强：没有"公司/集团"后缀的行政机构（如"某某市版权局"）、名称里带括号注释的公司（如"辰星信息安全科技（北京）有限公司"）现在都能遮住；括号里只是"甲方/乙方"这类角色批注时不会误遮。

### 3. money 金额实体（默认关闭）

可识别"¥金额""X 万元/亿元"。**默认不开启**——金额保留明文，方便让 AI 继续算账和统计。需要时在配置里显式启用。
